WFR Race Results - Privacy Policy

Last updated: 2 November 2026

About the App

WFR Race Results is operated by Weir Family Racing. It automatically retrieves publicly available motorsport results from MYLAPS/Speedhive and publishes selected results to the Weir Family Racing Facebook Page.

Information We Access

The app processes race event names, session names, driver names, finishing positions, lap counts and lap times. It also uses Facebook Page access permissions and an access token to publish posts to our own Page.

The app is not designed to collect Facebook visitors' personal information, private messages or contact details.

How Information Is Used

Race results are formatted into Facebook posts. Limited result identifiers and Facebook post IDs are retained to prevent duplicate publication.

Storage and Security

Automation configuration and publishing records are maintained in a private GitHub repository. Facebook credentials are stored as GitHub Actions secrets.

Third-Party Services

The automation uses MYLAPS/Speedhive, Meta/Facebook and GitHub. These services have their own privacy policies.

Data Retention and Deletion

Publication records are retained as needed to operate the automation and avoid duplicate posts. To request correction or deletion of information we control, contact us using the email address below.
